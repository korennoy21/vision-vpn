# Безопасный переход с текущего SEVER 0.4 на VISION

VISION 0.1.0 специально сохраняет серверный wire identifier `sever1`, формат профиля v2 и существующую структуру control DB. Это позволяет менять интерфейсы и клиентские приложения отдельно от миграции протокола.

Перед обновлением рабочего VPS обязательно сохраните:

- каталог данных панели (`data` / bind mount);
- `master.key`;
- `panel.env`;
- `node.env`;
- `node.json`;
- каталог данных Caddy;
- текущий исходный каталог приложения.

Не выполняйте `docker compose down -v` при переходе.

Первый rollout рекомендуется делать как code-only update панели и отдельную установку нового Android APK на тестовое устройство. После проверки панели, профиля, WSS 101, трафика и ручного отключения можно переходить к следующему клиенту.

Новые multi-protocol engines не следует включать одновременно. Каждый adapter должен пройти отдельный набор тестов: импорт, connect/disconnect, DNS, IPv4/IPv6 policy, split routing, sleep/resume, Wi-Fi/LTE handover, server failover и утечки.

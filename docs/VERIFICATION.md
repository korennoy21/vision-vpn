# Фактический отчёт — 0.3.0 / 10.09.2026

Полный запуск: **36 тестов, OK, пропусков нет**, 3.363 секунды.
Добавлены семь тестов `test_obfs4_adapter.py`: двусторонний IPv4 и PING/PONG
через SOCKS-заглушку с настоящим TLS, аргументы PT, отказ от SOCKS no-auth,
отсутствие прямого fallback, неверный TLS/токен, проверка профиля и loopback bind.
Зависание первоначального стенда при завершении исправлено: активные соединения
закрываются до ожидания закрытия слушателя.

**Реальный obfs4 не запускался.** Внешняя обфускация, зондирование и обнаруживаемость
не проверены; SOCKS-заглушка не выполняет обфускацию. Конфигурация внешнего PT —
шаблон. Полная мобильная сборка и интеграция obfs4 на телефонах отсутствуют.
Указанные ниже измерения 93/82 относятся только к WSS в выпуске 0.2.0.

- Синтаксический разбор 11 Java-файлов через JDK JavacTask.parse().
- Проверка синтаксиса Python, JSON, YAML, XML.
- Миграция тестового v1-профиля в v2: user/token сохранены, выходной файл mode 0600.
- Запись реальных зашифрованных TCP/TLS потоков в loopback relay: 100 PING старого

Тестовые токены и ключи — временные локальные фикстуры, не конфигурация реального
сервера. Сертификаты эксперимента удалены после выполнения.

## Границы проверки

- Во всех туннельных тестах TUN заменён очередью в памяти. Kernel routing/NAT и
  выход в интернет не проверены.
- JDK-тест WSS использует стандартный клиент Java, **не OkHttp Android**. Wire.java
  проверяется реально, VpnService/Keystore/защита сокетов/OkHttp — нет.
- Полная сборка Android APK отсутствует. Разбор синтаксиса не является проверкой
  типов Android API или внешних зависимостей.
- Swift/iOS не компилировался. URLSessionWebSocketTask внутри Packet Tunnel,
  Keychain, includeAllNetworks, обход собственного TUN и обработка redirects
  должны проверяться на iPhone.
- nginx-конфигурация не прошла nginx -t здесь и не участвовала в измерениях.
  Локальные HTTPS-проверки использовали настоящий aiohttp-сервер с тестовым сайтом.
- systemd/nftables на VPS, DNS/IPv6-утечки, отключение/переключение сетей,
  нагрузка, батарея и многосуточная работа не проверены.
- Эмулятора ТСПУ, независимого DPI-классификатора, датасета обычных приложений
  и полевых измерений в сетях операторов нет. Процент обнаружения не измерялся.
- Поддержка VLESS, AmneziaWG, OpenVPN и других движков не добавлена.

Результат разработки: **экспериментальные исходники с новым WSS-транспортом,
проверенной серверной/Java-кодековой совместимостью и устранением двух конкретных
лабораторных признаков**. Готовность к раздаче клиентам и незаметность не заявляются.

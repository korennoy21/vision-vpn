# Проверки и изменения 0.4.0 — 10.09.2026

## Реализовано

Панель с серверной авторизацией, scrypt-паролем, HttpOnly/Secure/SameSite-cookie,
CSRF и проверкой Origin для административных мутаций. Токены сессий, клиентов и
агентов индексируются по SHA-256; возвращаемые клиентские секреты и токены агентов
хранятся с AES-256-GCM и отдельным master.key. Доступ по подписке — bearer-секрет
в HTTPS URL; access logs выключены, ответы не кешируются.

Клиенты создаются транзакционно, получают уникальные адреса и назначения узлов.
Изменение адреса узла сохраняет VPN-токен и URL. Отключение/истечение доступа
исключает пользователя из конфигурации агента. Смена ключей отзывает и VPN-токен,
и прежнюю ссылку. Администратор может сменить пароль через CLI; сессии отзываются.

Агент получает правила через HTTPS, не следует перенаправлениям, принимает только
проверенный ограниченный набор пользователей. Он закрывает изменённые/отозванные
сессии и сообщает число соединений. При потере обновления правил действует
60-секундный срок доступа, контролируемый отдельной задачей.

Android/iOS: HTTPS-импорт с ограничением размера, без HTTP redirect; профиль
хранится в системном защищённом хранилище. Android обновляет его при очередном
цикле подключения; iOS — при подключении через UI. Ссылку из ответа сервера
подменять нельзя: сохраняется импортированная пользователем ссылка.

## Фактически выполнено

- Полный unittest: **43 теста, OK**, 4.566 с на первом полном запуске 0.4.
- Семь новых интеграционных тестов: login/CSRF/Origin/logout; отсутствие секретов
  в общем состоянии; сохранение ключей при смене endpoint; отзыв и ротация;
  сроки/отключение узла/изоляция агентов; транзакционный rollback; шифрованное
  хранение; панель → агент → настоящий WSS → IPv4 → закрытие живой сессии;
  срок доступа агента; смена пароля и ограничение попыток входа.
- Прежние 36 тестов ядра/WSS/obfs4-адаптера прошли после изменения Gateway.
- Разобран синтаксис 10 Java-файлов, Python, JavaScript, YAML, XML, shell.
- Сетевые проверки использовали localhost и временные сертификаты/ключи.

## Не выполнено

- Android APK/Gradle/SDK, Swift/Xcode/подпись, тесты на телефонах.
- Docker build/Compose запуск, Caddy validate и ACME.
- TUN и NAT ядра: в тестах TUN — очередь в памяти.
- Browser UI QA: браузерные тесты не запрашивались и не выполнялись.
- WebMCP: добавлен необязательный read-only инструмент состояния; поддерживаемый
  браузерный контекст для его проверки отсутствовал.
- DPI/ТСПУ, полевая доступность, батарея, длительная нагрузка и восстановление VPS.

В архиве нет тестовых приватных ключей, базы пользователей, подписок и node.json.
Docker/Compose шаблоны рассчитаны на отдельный Linux VPS и не модифицируют существующие
3ax-ui конфигурации. Актуальность security updates закреплённых зависимостей
требует проверки перед эксплуатацией.

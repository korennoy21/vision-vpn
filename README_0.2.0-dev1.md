# VISION VPN Suite 0.2.0-dev1

Продолжение сохранённого VISION VPN Suite 0.1.0 без смены утверждённого дизайна.

Состав проекта:

- `android-client/` — VISION VPN Android;
- `ios-client/` — VISION VPN iOS;
- `android-admin/` — VISION Control Android;
- `control/` — VISION Control Web/backend;
- `sever/`, `ops/` — VISION compatible server transport/deployment;
- `.github/workflows/verify.yml` — server tests, два Android APK и iOS compile-check.

Точный перечень реализованного и ещё незавершённого см. в `BUILD_STATUS.md`.
